# Sejarah dan Filosofi HIMATIFA

> **Berinovasi, Berkolaborasi, Berprestasi!**
>
> Sebuah perjalanan besar bisa dimulai dari percakapan sederhana. Sejak 10 Oktober 2020, HIMATIFA menjadi ruang bagi mahasiswa Informatika untuk menyatukan aspirasi, bertumbuh lintas generasi, dan melangkah bersama.

## Tentang proyek

Proyek ini menyajikan perjalanan HIMATIFA dan filosofi logonya dalam sebuah presentasi web interaktif. Bukan sekadar mengenang masa lalu, kisah ini mengajak setiap generasi untuk menjaga identitas, mengembangkan ilmu, memperluas kolaborasi, dan meneruskan kontribusi.

Presentasi mencakup:

- Awal berdirinya HIMATIFA dan tonggak perjalanannya.
- Regenerasi, pertumbuhan, dan perluasan jejaring.
- Makna elemen-elemen dalam logo HIMATIFA.
- Nilai kebersamaan, keilmuan, dan semangat untuk terus berkarya.

## Cara membuka

Tidak perlu instalasi atau dependensi tambahan. Buka [index.html](./index.html) menggunakan browser modern.

## Deploy ke Vercel

Impor repository ini di Vercel dan gunakan pengaturan default. Situs berupa halaman statis, sehingga tidak memerlukan framework, build command, maupun output directory khusus. Vercel akan menyajikan `index.html` dari root repository sebagai halaman utama.

## Navigasi presentasi

- **Panah kiri / kanan**: berpindah slide.
- **M**: membuka daftar slide.
- **N**: menampilkan atau menyembunyikan catatan pemateri.
- **F**: mengaktifkan atau keluar dari layar penuh.
- Pilih elemen pada bagian filosofi logo untuk membaca maknanya.
